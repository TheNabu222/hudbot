# Cavebot Studio — Project Instructions

## Overview
Cavebot Studio is a no-code point-and-click game builder designed to resolve continuity/fragmentation issues in the existing "hudbot" project. It includes a bundled playable game engine and exports standalone HTML.

## Technical Architecture
- **State Management**: Zustand store (`lib/store.ts`) — all project state in a single store, persisted to localStorage
- **No Database**: This is a local creative tool using localStorage for persistence
- **Scene Graph**: React Flow for visual node-based scene connections
- **Schema**: v2 schema with typed facts, condition groups, actions (see `lib/types.ts`)
- **Import**: `lib/importer.ts` normalizes v1 hudbot JSON → v2 schema (handles prose flags, legacy enum values, broken refs)
- **HTML Export**: `lib/html-exporter.ts` generates standalone HTML with embedded vanilla JS game engine
- **Sample Data**: `/public/sample-game.json` — the cavebot game export (31 scenes, 36 characters)

## UI Design
- **Dark theme**: `#0d0d1a` background, Y2K/Lisa Frank accent colors (yellow, pink, cyan, purple gradients)
- **Tab-based layout**: Scene Graph | Scene Editor | Dialogue | Characters | Quests | Items | Needs/Stats | Settings | Preview
- All panels are client-side components loaded via `next/dynamic` with SSR disabled

## Color Tokens
- Primary: yellow (`#fbff00`)
- Secondary: purple (`#8b5cf6`)  
- Accent: cyan, pink
- Surface: `#111128`, `#1a1a3a`, `#0f0f24`
- Borders: `#2a2a4a`, `#1f1f3f`, `#333366`

## Key Files
- `components/studio/studio-app.tsx` — main app shell with header, tab bar, panel routing
- `components/studio/panels/*` — all editor panels
- `lib/store.ts` — Zustand store with all CRUD operations
- `lib/types.ts` — complete v2 schema type definitions
- `lib/importer.ts` — v1→v2 import/normalization
- `lib/html-exporter.ts` — standalone HTML game engine export
- `lib/id-utils.ts` — ID generation, slugification, flag→key conversion
